## Сейчас в работе

### Admission Radar
Система аналитики и прогнозирования хода приёмной кампании университета. Проект объединяет импорт данных, контроль качества, сравнение по годам, прогнозирование и управленческие отчёты.

### Математическое моделирование приёмных кампаний
Диссертационное исследование о моделях и методах управления приёмными кампаниями высших учебных заведений.

### Курсы по искусственному интеллекту
Образовательные программы для преподавателей, специалистов и начинающих пользователей: практическое применение ИИ, локальные модели, работа с текстом, изображениями, видео и данными.

### Система напоминаний о приёме лекарств
Telegram-бот, который напоминает о приёме лекарств и уведомляет близкого человека, если приём пропущен. Сейчас проект проходит тестирование.
